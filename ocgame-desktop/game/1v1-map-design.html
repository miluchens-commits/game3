核心設計理念

不是單純讓地圖變複雜，而是讓「地形、走位、預判、心理戰、槍法」全部影響勝負。

🎯 核心體驗

「敵人一直就在附近，但你永遠不知道他下一秒會從哪裡出現。」

設計一張讓兩名玩家幾乎一直處於「敵人就在附近，但不知道下一秒從哪裡出現」狀態的立體競技地圖。

  • 不要設計成大型空曠 FPS 地圖
  • 不要讓玩家長時間找不到敵人
  • 中小型地圖，玩家平均幾秒內就有機會接觸敵人
  • 不要讓兩人一出生就直接互相看到

⚔ 中央主戰區

整張地圖最重要的戰鬥區。不要做成單純的大廣場。

由以下元素組成：

大型掩體 半高牆 破損牆壁 柱子 箱子 斜坡 小型高台 半地下區域

玩家可以：正面攻擊、躲掩體、繞側面、跳到高處、從地下接近、快速撤退。

⚡ 中央能量核心

取得後暫時獲得特殊能力：

  • 攻擊力提升
  • 移動速度提升
  • 護盾
  • 特殊武器
  • 敵人位置短暫顯示

⚠ 取得時玩家位置會短暫暴露給敵人 — 高風險、高報酬！

🏗 上層區域（第二層）

透過樓梯、斜坡、跳台、破損平台進入。

  • 可以看到中央部分區域
  • 只有少量掩體，不夠安全
  • 長時間停留架槍 → 容易被地下或側翼繞後
  • 「高處」= 高視野、高風險
🕳 地下區域

不要只有一條直線。設計成多路徑、多房間的地下網路。

包含：入口A、入口B、分叉路、小房間、狹窄通道、隱藏出口、中央地下區域。

可連接中央、左側翼和右側翼。

繞後 逃跑 偷襲 快速轉移

部分地下出口必須位於玩家意想不到的位置。

🔄 左側翼 vs 右側翼
◀ 左側翼 — 廢墟區
  • 較寬的道路
  • 大型破損牆壁
  • 多個掩體
  • 中距離射擊
  • 少量高低差
  • 至少兩條不同路線
適合：快速移動、中距離槍戰、追擊
右側翼 — 室內區 ▶
  • 房間、走廊、轉角
  • 小型掩體
  • 窄門
  • 短距離射擊
  • 「看起來安全但有第二入口」的房間
適合：近戰、伏擊、偷襲、心理戰
🔍 隱藏捷徑

熟悉地圖後才能掌握的進階路線。

可破壞牆壁 隱藏通道 可跳上平台 地下入口 窗戶 通風管道 特殊跳躍路線

數量不能太多。讓高手可以利用地形做出：繞後、反繞後、快速逃脫、突然攻擊。

👁 視線設計

非常重要。不要讓整張地圖擁有長距離直線視野。

大量使用：

牆壁 柱子 掩體 高低差 轉角 半透明障礙 破損結構
🧠 資訊不對稱

玩家應該經常知道「敵人在附近」，但不知道「敵人現在到底在哪裡」。

讓玩家必須透過腳步聲、槍聲、影子、短暫視線、地圖記憶判斷敵人位置。

🔥 戰鬥節奏

希望玩家經常產生以下循環：

發現敵人
→
短暫交火
→
其中一人撤退
→
另一人追擊
→
敵人突然消失
→
開始猜測位置
→
敵人從側面出現
→
再次交火
→
其中一人繞後
→
近距離決戰

不要讓戰鬥一直固定在同一個位置。玩家應該會不斷移動。

🛡 防龜機制

避免玩家一直躲在同一個地方。

  • 側翼路線
  • 地下入口
  • 高台射擊角度
  • 可破壞掩體
  • 中央特殊道具
  • 縮小戰鬥區域
  • 時間限制

如果玩家長時間不交戰，讓中央區域逐漸變成更重要的位置。

🏁 最終決戰

回合時間快結束時：

  • 中央區域成為主要戰鬥區
  • 部分外圍路線逐漸失去優勢
  • 迫使兩名玩家逐漸接近中央
⚔ 最終狀態

1V1 · 近距離 · 高壓力 · 沒有太多躲藏空間
